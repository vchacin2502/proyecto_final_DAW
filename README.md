# CaFit

CaFit es una aplicación web pensada para llevar un control sencillo y visual de la alimentación diaria. Permite registrar comidas, consultar el progreso nutricional del día y revisar rápidamente qué se ha comido en cada momento.

## ¿Para qué sirve?

La aplicación ayuda a organizar la alimentación de forma práctica. Cada usuario puede guardar alimentos habituales, crear comidas con esos alimentos y ver un resumen de calorías y macronutrientes para tener una idea clara de su consumo diario.

## Características principales

- Registro de alimentos propios con sus valores nutricionales.
- Creación de comidas diarias como desayuno, almuerzo, cena o snacks.
- Resumen visual del progreso de calorías y macros del día.
- Consulta rápida de cada comida con su detalle y opciones para editar o eliminar.
- Estadísticas y seguimiento para revisar la evolución de la alimentación.
- Chat interno para compartir dudas o comentarios con otros usuarios.
- Panel de administración para gestionar usuarios, incidencias y contenido de la plataforma.

## Cómo funciona

1. El usuario accede a su cuenta o se registra.
2. Completa su perfil y, si quiere, fija objetivos de calorías y macronutrientes.
3. Añade alimentos a su catálogo personal.
4. Crea una comida seleccionando los alimentos y las cantidades que ha consumido.
5. La aplicación calcula automáticamente el resumen nutricional de esa comida y del total del día.
6. Desde el dashboard puede ver el progreso diario y consultar cada comida con un clic.

## Pantallas principales

### Dashboard

Es la pantalla principal. Muestra el progreso del día, los macros consumidos y el listado de comidas registradas. Desde aquí se puede entrar al detalle de una comida, editarla o borrarla.

### Alimentos

Permite consultar y gestionar el catálogo personal de alimentos. Desde esta sección se pueden crear nuevos alimentos o modificar los existentes.

### Comidas

Sirve para registrar lo que se ha comido en un día concreto. Primero se selecciona el tipo de comida y después se añaden los alimentos y cantidades.

### Estadísticas

Muestra una visión más global del seguimiento nutricional y del calendario de comidas.

### Chat

Espacio de comunicación entre usuarios para resolver dudas o compartir información.

## Uso rápido

Si es la primera vez que entras, lo normal es seguir este orden:

- Crear una cuenta o iniciar sesión.
- Completar el perfil.
- Añadir algunos alimentos al catálogo.
- Registrar una comida con esos alimentos.
- Revisar el dashboard para ver el resumen del día.
